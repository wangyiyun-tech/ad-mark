# 付费推广标记（辅助）ad-mark

一个**可选安装**的跨浏览器扩展：在你浏览网页时，把网页**自带**的付费推广 / 广告条目用一个小红牌「广告」明显地标出来，帮你一眼分清哪些是自然结果、哪些是推广内容。

> 简单说：网站自己标了「广告 / 推广 / 赞助」的地方，本来可能显示得很不起眼，这个扩展会帮它挂一块显眼的小红牌。它**不自行判定**什么是广告，也不删除、不屏蔽任何东西——只是把网站已经告诉你的事，显示得更清楚。

## ✨ 它做什么

- 在识别出的付费推广 / 广告条目**右下角**，显示一个小红牌「广告」
- 鼠标悬浮在红牌上，会弹出免责说明
- 支持**动态加载**的页面（往下翻、刷新出新内容时也会自动补标记）
- 完全在本地运行：**不联网、不上传任何数据**

## 🚫 它不做什么（免责边界）

| 做 | 不做 |
|---|---|
| 在识别出的推广条目右下角显示小红牌「广告」 | 拦截 / 屏蔽 / 删除广告请求或元素 |
| 鼠标悬浮显示免责说明 | 修改网页广告内容 / 拦截广告点击 / 篡改广告数据 |
| 只在本地页面上叠加提示 | 上传数据、联网、针对特定网站 |

## 🔍 识别原理

本扩展只认**网页自身已有的推广标识**，包括：

1. **推广标签文字**：网站自己展示的「广告 / 推广 / 赞助 / Sponsored / Promoted」等小字（含百度等搜索引擎常见的推广隐藏标记，如 `.ec-tuiguang`）
2. **语义属性**：`aria-label` / `title` / `data-*` 里写明的推广标记
3. **推广类 CSS 类名**：搜索引擎常见的推广样式类

它**不会**根据链接内容或商品内容去猜「这个像广告」，所以不会冤枉正常内容，但也可能漏标——识别结果仅供参考。

另外，网页**顶部导航栏 / 站点菜单**里的按钮一律不标记：那是网站自己的功能入口（比如 GitHub 右上角菜单里的「赞助」），不是对某条内容的推广标注。

## 📥 安装教程

### 方式一：下载 zip（推荐）

1. 打开本仓库的 [Releases 页面](https://github.com/wangyiyun-tech/ad-mark/releases)
2. 下载最新的 `ad-mark-x.x.x.zip`
3. 解压到一个**长期保留**的目录（解压后别删，浏览器要一直读这个目录）
4. 按下面的「浏览器加载步骤」操作

### 方式二：Download ZIP / git clone

点击仓库右上角绿色 `<> Code` 按钮里的 `Download ZIP`，或：

```bash
git clone https://github.com/wangyiyun-tech/ad-mark.git
```

> 注意：GitHub 的 Download ZIP 解压后文件夹名会带 `-main` 后缀，直接用没问题。

### 浏览器加载步骤

#### A. Chrome / Edge / Brave / Vivaldi / Opera 等 Chromium 系浏览器

1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions` 回车
   - Edge：地址栏输入 `edge://extensions` 回车
2. 打开右上角（Edge 是左侧）的「**开发者模式**」开关
3. 点「**加载已解压的扩展程序**」（Edge 叫「加载解压缩的扩展」）
4. 选中解压出来的文件夹（**里面有 `manifest.json` 的那一层**）
5. 完成！工具栏会出现扩展图标

#### B. Firefox

1. 地址栏输入 `about:debugging#/runtime/this-firefox` 回车
2. 点「**临时载入附加组件**」
3. 选择文件夹里的 `manifest.json`
4. ⚠️ Firefox 这种方式是**临时安装**，重启浏览器后会失效；要长期使用需按 Firefox 官方流程签名发布

#### C. 卡片浏览器

在「设置 → 广告标记扩展（可选）」里点「加载扩展」，选择本目录即可。

## 📖 使用说明

装好后**不需要任何配置**，直接打开任意网页即可：

1. 页面里如果有网站自己标注的推广条目，右下角会出现小红牌「广告」
2. 鼠标悬浮在红牌上，可以看免责说明
3. 点扩展图标，会看到「已在本地运行」的小面板

**没有看到红牌？** 正常——只有网页自带推广标识时才会出现。可以去搜索引擎搜个热门关键词看看效果。

### 卸载

在浏览器的「扩展管理」页里点「移除」即可。卸载后所有标记立即消失，**不留任何数据**。

## ❓ 常见问题

<details>
<summary><b>为什么有些明显的广告没被标出来？</b></summary>

因为本扩展只认**网站自己标注**的推广标识。如果网站没标注（或用了扩展不认识的标记方式），就不会被标。它不靠猜，宁可漏标也不误标。
</details>

<details>
<summary><b>会不会拖慢浏览器 / 有安全问题吗？</b></summary>

不会。整个扩展只有几百行代码，无任何网络请求，不上传任何数据，代码全部开源在仓库里，可以自行审查。
</details>

<details>
<summary><b>支持手机浏览器吗？</b></summary>

Firefox for Android 支持临时载入；Chromium 系手机浏览器大多不支持加载本地扩展。
</details>

<details>
<summary><b>为什么它是「可选安装」的？</b></summary>

本扩展从「卡片浏览器」本体中独立出来，不带任何品牌预装。装不装、开不开，完全由你自己决定。
</details>
